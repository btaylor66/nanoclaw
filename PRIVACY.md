# Privacy Policy

This NanoClaw instance is a personal, self-hosted assistant run by a single individual for their own household. It is not offered as a service to the public.

## What data is accessed

When you connect a Google account, the app requests access to Google Calendar (and optionally other Google services you explicitly authorize) so the assistant can read and manage your events on your behalf.

## How data is used

Data retrieved from Google APIs is used only to fulfill requests you make to the assistant. It is processed on hardware controlled by the operator and is not sold, shared with third parties, or used for advertising.

## Storage and retention

OAuth tokens and any cached data are stored locally on the operator's own machines. You can revoke access at any time from your Google Account permissions page (https://myaccount.google.com/permissions), which immediately invalidates the stored tokens.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Contact

Questions about this policy can be directed to the repository owner via GitHub.
